# BUY NOW OR LIVE 스케줄 수집기 (크롬 확장프로그램)

Vercel 서버 IP가 올리브영 WAF / G마켓 Cloudflare 챌린지에 막혀 있어서,
이 확장프로그램이 설치된 실제 브라우저(실사용자 IP)로 주기적으로 두
사이트를 방문해 편성표를 수집하고 백엔드로 전송한다.

## 설치 방법 (개발자 모드, 배포용 아님 - 본인 브라우저에서만 사용)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 스위치 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 저장소의 `extension` 폴더 선택
5. 설치되면 브라우저 툴바에서 확장프로그램 아이콘 클릭 → 팝업이 열림
6. **INGEST_SECRET** 입력란에 시크릿 값 붙여넣기 → **저장** 클릭
   (GitHub Actions 시크릿/Vercel 환경변수에 설정한 것과 동일한 값)
7. **지금 바로 수집** 버튼으로 한 번 테스트 실행 → 결과가 아래에 표시됨

## 동작 방식

- 설치되면 20분마다 자동으로 실행됨 (`chrome.alarms`)
- 실행될 때 크롬이 켜져 있어야 함 (백그라운드에서 조용히 동작, 창을 띄우거나
  포커스를 뺏지 않음 - G마켓 수집을 위해 비활성 탭을 하나 잠깐 열었다가 닫음)
- 수집한 데이터는 `https://buynoworlive.vercel.app/api/ingest` 로 전송되어
  KV 캐시에 저장되고, `/api/crawl?platform=oliveyoung`,
  `/api/crawl?platform=gmarket` 이 그 캐시를 그대로 서빙함

## 혜택 정보 수집 (benefit-content.js)

SSG/올리브영/G마켓/CJ온스타일의 방송 상세 페이지를 직접 열면, 페이지 안의
"혜택" 배너 이미지를 찾아 `/api/benefit`으로 전송한다. 서버가 캐시에 없으면
그때 한 번만 OCR.space로 이미지 텍스트를 읽어 할인율/쿠폰/증정품을 파싱해
저장하고, 이후 같은 방송은 캐시에서 바로 꺼내 쓴다 (OCR은 방송당 1회만).
별도 설정 없이 자동으로 동작하고(OCR 키는 Vercel 서버 쪽 환경변수), 이미지를
못 찾으면 조용히 아무 것도 하지 않는다.

## 시크릿을 소스에 넣지 않은 이유

압축해제 확장프로그램은 소스가 그대로 보이기 때문에, 시크릿을 코드에
하드코딩하지 않고 `chrome.storage.local`에 저장해서 팝업에서 직접
입력하도록 만들었다. 컴퓨터를 바꾸거나 확장프로그램을 다시 설치하면
시크릿을 다시 입력해야 한다.
